# Запуск пакетной сборки

В комплекте репозитория сборщик находится в `teamly-superarticle/scripts/teamly-code.mjs`. Начни с [инструкции по установке и запуску](../README.md), затем открой [формат плана](../teamly-superarticle/references/code-mode.md). Примеры каркаса и ТБД лежат в `teamly-superarticle/examples/code-mode/`.

Если навыки установлены раздельно, используй папку установленного `teamly-superarticle`. Передай план и отдельный профиль Chrome конкретного хоста. Перенеси подтверждённые ссылки и статусы в паспорт.
