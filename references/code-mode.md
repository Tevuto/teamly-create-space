# Запуск пакетной сборки

Общий сборщик находится в соседнем установленном навыке `teamly-superarticle`. Открой [инструкцию запуска и формат плана](../../teamly-superarticle/references/code-mode.md). Примеры расположены в `teamly-superarticle/examples/code-mode/`. Используй план и профиль конкретного хоста, затем перенеси подтверждённые ссылки и статусы в паспорт.

Для шагов, которые требуют сверки интерфейса, используй справки текущего навыка. Сохраняй все требования к наполнению и проверке исходного задания.
